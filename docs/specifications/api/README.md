# Technical Specifications

This directory contains API contracts, type signatures, and interface specifications for the Abu OS 98 Web Kernel.

## Organization

- **component-api.md** - Component props, events, and usage
- **store-api.md** - Store interfaces and actions
- **plugin-api.md** - Plugin registration and lifecycle
- **kernel-api.md** - Kernel interface contracts
- **types.md** - TypeScript type definitions
- **css-api.md** - CSS classes and SCSS mixins

## Reference

Detailed behavior specifications are in:
- `/docs/architecture/` - System architecture and behavior
- `/docs/design/` - Visual and component design specs

These technical specs define the **interfaces** and **contracts** for implementation.
