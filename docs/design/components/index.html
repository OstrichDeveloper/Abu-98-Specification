Component Library

The Abu OS 98 component library provides pixel-perfect Windows 98 UI components built with modern web technologies.

Core Components​

Window Components​

  • Window - Main window container
  • Titlebar - Window title bar with controls
  • Titlebar Button - Window control buttons
  • Window Chrome - Window border and styling

Desktop Components​

  • Desktop - Main desktop container
  • Desktop Icon - Desktop shortcuts and icons
  • Taskbar - Bottom taskbar
  • Taskbar Button - Application buttons
  • Start Button - Windows start button
  • Start Menu - Start menu system
  • System Tray - System notification area
  • Clock - System clock display

Form Components​

  • Button - Standard buttons
  • Input - Text input fields
  • Checkbox - Checkbox controls
  • Radio - Radio button controls
  • Select - Dropdown select boxes
  • Slider - Range sliders
  • Progress Bar - Progress indicators

Dialog Components​

  • Dialog - Modal dialogs
  • Message Box - Alert dialogs
  • Group Box - Grouped form controls

Menu Components​

  • Menu Bar - Application menu bars
  • Menu Item - Individual menu items
  • Context Menu - Right-click menus

Utility Components​

  • Status Bar - Status information display
  • Tab Control - Tabbed interfaces
  • Tooltip - Hover tooltips
  • Resize Handle - Window resize handles
  • Theme Toggle - Theme switching
  • Volume Control - Audio volume control

Terminal Component​

  • Terminal - Command line interface

Usage​

All components follow the Windows 98 design system and are built to be:

  • Pixel Perfect - Exact recreation of Windows 98 appearance
  • Accessible - ARIA compliant and keyboard navigable
  • Themeable - Support for light and dark themes
  • Performant - Optimized for modern web browsers
  • Type Safe - Full TypeScript support

Getting Started​

To use these components in your application:

import { Window, Titlebar, Button } from '@melalawi/abu-web-kernel';

// Create a new window
const window = new Window({
  title: 'My Application',
  width: 400,
  height: 300
});

See the individual component documentation for detailed usage examples and API references.
