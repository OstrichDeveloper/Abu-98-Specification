# Abu OS Design System

Welcome to the Abu OS Design System documentation. This section contains the complete design philosophy, visual system, and guidelines for the Abu OS ecosystem.

## Philosophy

The Abu OS design system is built on the principles of authenticity, consistency, and usability. We strive to recreate the Windows 98 aesthetic pixel-perfectly while maintaining modern web standards and accessibility.

- **[Visual System](visual-system.md)** - Complete visual design system and principles
- **[Color System](color-system.md)** - Single source of truth for all colors, philosophy, and usage
- **[Typography](typography.md)** - Font system, hierarchy, and usage guidelines  
- **[Icon System](icon-system.md)** - Icon philosophy, library, and implementation
- **[Component Design](component-design.md)** - Component design principles and patterns
- **[Accessibility](accessibility.md)** - Accessibility guidelines and best practices

## Using This Documentation

All component documentation throughout Abu OS references colors by name (e.g., "Windows Blue") with hyperlinks to the [Color System](color-system.md) page. This ensures a single source of truth and easy updates.

## Contributing

When creating new components or updating existing ones, always reference the design system to maintain consistency across the ecosystem.
