# Typography System

Font system and hierarchy for Abu OS.

## System Fonts

Abu OS uses pixel-perfect Windows 98 system fonts:

- **MS Sans Serif** - System UI font
- **Tahoma** - Alternative system font
- **Fixedsys** - Terminal font

## Implementation

Fonts are embedded as TTF files in the kernel package and loaded via CSS.
